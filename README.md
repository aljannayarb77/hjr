# منصة تنظيم وحجز مواعيد دخول الحِجر بالمسجد الحرام

تطبيق ويب متكامل واحترافي باللغة العربية (RTL) بتصميم عصري مستوحى من الطابع الإسلامي والعمارة المكية، لتنظيم حجز مواعيد دخول الحِجر، وإصدار تذاكر إلكترونية برمز QR فريد، مع شاشة تحقق للموظفين ولوحة تحكم متقدمة للإدارة.

> **تنبيه وإخلاء مسؤولية تنظيمي:**
> هذا المشروع نموذج تنظيمي وتقني مستقل لتنظيم الحجوزات والتفويج، ولا يتبع لأي جهة حكومية أو رسمية (مثل الهيئة العامة لشؤون المسجد الحرام أو وزارة الحج والعمرة / نسك)، ولا يُعد بديلاً عن التصاريح الرسمية الصادرة من الجهات المختصة ما لم يتم ربطه واعتماده رسميًا.

---

## 🌟 الميزات الرئيسية

1. **واجهة الزائر (Mobile-First & Accessible):**
   - هوية بصرية إسلامية راقية (أخضر زمردي، ذهبي رملي، رخام أبيض) وخطوط عربية واضحة (Cairo و Tajawal).
   - صفحة رئيسية متكاملة (Header, Hero, طريقة الحجز, التعليمات, الأسئلة الشائعة, Footer مع إخلاء المسؤولية).
   - معالج حجز متعدد الخطوات (4 خطوات) مع مؤشر تقدم بصري.
   - تقويم تفاعلي لاختيار اليوم وعرض الفترات الزمنية مع المقاعد المتبقية وشارات الحالة (متاح، مكتمل، منتهي).
   - فحص السعة والتحقق المتزامن على مستوى الخادم لمنع التنافس وحجز المواعيد الممتلئة (Overbooking Prevention).
   - منع تكرار الحجز لنفس رقم الهوية في ذات اليوم.

2. **التذكرة الإلكترونية ورمز QR الفريد:**
   - إصدار فوري لرقم حجز موحد (مثل `HJ-2026-XXXX`).
   - توليد رمز QR مشفر يحتوي على توكن رقمي آمن للتحقق دون كشف البيانات الشخصية الحساسة.
   - خيارات متعددة: تحميل التذكرة، طباعة التذكرة بجودة عالية (A4 متجاوب)، ومشاركة الحجز عبر WhatsApp.

3. **الاستعلام عن الحجز وإلغاؤه:**
   - استعلام سريع وآمن برقم الحجز + رقم الجوال.
   - إمكانية إلغاء الحجز مع تأكيد مسبق وفق سياسة الساعات المحددة، واستعادة المقعد تلقائياً للمستفيدين الآخرين.

4. **شاشة تحقق وماسح QR للموظفين (`/scanner.html`):**
   - ماسح كاميرا مدمج متجاوب مع الهواتف الذكية (`html5-qrcode`) مع خيار الإدخال اليدوي.
   - استجابة فورية مرئية:
     - ✓ **حجز صالح**: بطاقة نجاح خضراء وتفاصيل الزائر + زر "تسجيل الدخول" (يحول الحالة فوراً إلى `USED`).
     - ⚠️ **حجز مستخدم مسبقاً**: تحذير برتقالي مع تاريخ ووقت الدخول السابق لمنع تكرار الاستخدام.
     - ✕ **حجز ملغى**: إشعار أحمر بأن التذكرة ملغاة.
     - ✕ **رمز غير صالح**: إشعار برفض الرمز غير المسجل.
     - تنبيه في حال كان تاريخ الحجز مختلفاً عن تاريخ اليوم.

5. **لوحة تحكم الإدارة الشاملة (`/admin.html`):**
   - تسجيل دخول آمن بنظام الصلاحيات (RBAC: `ADMIN` و `STAFF`).
   - بطاقات إحصائية ورسم بياني لحجم الحجوزات والسعة للأيام القادمة.
   - **إدارة المواعيد**: إضافة موعد، تحديد السعة، تفعيل/تعطيل، وحذف.
   - **إدارة الحجوزات**: بحث بالاسم والرقم والجوال، فلاتر حسب التاريخ والحالة، تسجيل دخول يدوي، وإعادة إرسال التذكرة.
   - **التقارير والتصدير**: إحصائيات الفترات وتصدير فوري لبيانات الحجوزات إلى ملف Excel/CSV بترميز UTF-8 مع BOM.
   - **إعدادات النظام**: تعديل النصوص، سياسات الإلغاء، السعة الافتراضية، ورسائل التنبيه.
   - **سجل العمليات (Audit Logs)**: تسجيل دقيق لكل عملية حجز وإلغاء ومسح وتعديل.

## 🚀 تشغيل المشروع

### 1. المتطلبات:
- وجود بيئة Node.js (الإصدار 18 فما فوق).

### 2. بدء التشغيل:
```bash
# تشغيل الخادم
npm start

# لإعادة تهيئة البيانات التجريبية في أي وقت:
npm run seed

# لتشغيل الاختبارات الآلية الشاملة:
npm test
```

### 3. الروابط المباشرة:
- **الموقع الرئيسي للزوار:** `http://localhost:3000`
- **حجز موعد جديد:** `http://localhost:3000/book.html`
- **الاستعلام عن حجز:** `http://localhost:3000/inquiry.html`
- **شاشة ماسح QR للموظفين:** `http://localhost:3000/scanner.html`
- **لوحة تحكم الإدارة:** `http://localhost:3000/admin.html`
- **تسجيل الدخول:** `http://localhost:3000/login.html`

### 4. الحسابات التجريبية الافتراضية:
- **حساب المدير (Admin):**
  - اسم المستخدم: `admin`
  - كلمة المرور: `admin123`
- **حساب المشرف / الموظف (Staff):**
  - اسم المستخدم: `staff`
  - كلمة المرور: `staff123`

## 🔒 الأمان والتوسع المستقبلي

- **تشفير كلمات المرور:** باستخدام خوارزمية `bcrypt` مع Salt آمن.
- **جلسات العمل:** بواسطة توكنات `JWT` مشفرة ومحددة الصلاحية.
- **قاعدة البيانات:** صممت بهيكل معياري مستقل (Modular)، ويمكن ربطها مباشرة بقواعد بيانات PostgreSQL أو MySQL عند الانتقال لبيئة إنتاجية ضخمة دون الحاجة لتعديل الواجهات.
- **بوابات الإرسال (SMS / WhatsApp):** تم تجهيز وحدة `notificationService.js` بنظام قوالب وسجلات جاهزة للربط الفوري مع مزودي الرسائل مثل Unifonic أو Twilio أو WhatsApp Cloud API.
